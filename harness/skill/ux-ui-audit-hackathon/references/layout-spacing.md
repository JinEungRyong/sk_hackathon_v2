# B. 레이아웃·간격 (Layout & Spacing)

- 같은 역할의 Component가 같은 정렬 기준을 쓰는가?
- 좌우 정렬선이 이유 없이 흔들리지 않는가?
- Section 사이 간격과 Component 내부 간격이 구분되는가? (바깥 간격 > 안쪽 간격)
- 반복되는 요소(리스트, 카드)의 간격 리듬이 일정한가?
- 8px 기반 Grid / Spacing 스케일을 쓴다면, 스케일 밖의 임의 값이 반복적으로 섞여 있지 않은가?
- 한 화면의 정보 밀도가 지나치게 높지 않은가?
- 모든 내용을 Card로 감싸서 오히려 구조가 복잡해지지 않았는가?
- 화면 가장자리와 콘텐츠 사이에 충분한 여백이 있는가?
- 고정된 헤더나 버튼 영역이 콘텐츠를 과하게 가리지 않는가?
- 같은 종류의 Row / List Item 높이와 내부 정렬이 일관되는가?
- 반복 Component마다 Padding 규칙이 달라지지 않는가?

주의: 정확한 Spacing 수치를 받지 못했다면 "시각적으로 불일치"까지만 지적한다. 코드나 측정값 없이 "4px 차이" 같은 구체적 오차를 지어내지 않는다.
