# D. 컬러·접근성 (Color & Accessibility)

WCAG 2.x AA를 기본 참고 기준으로 쓴다.

## 텍스트 대비
- 일반 텍스트: 4.5:1 이상
- 큰 텍스트: 3:1 이상 (대략 24px 이상 Regular, 또는 18.66px 이상 Bold)

## 텍스트가 아닌 요소의 대비
- 상태와 경계를 이해하는 데 필요한 UI 요소(입력창 테두리, 아이콘, 토글, Focus 링)는 가능하면 3:1 이상

## 추가 기준
- 우선순위·상태·오류를 색상만으로 구분하지 않는다.
- 오류는 색상과 함께 텍스트, 아이콘, Label 중 하나 이상으로 알린다.
- 선택 상태를 색상 하나에만 의존하지 않는다. (`navigation-selected-state.md` 참고)
- Disabled 상태는 일반 상태와 구분되면서도, 필요한 텍스트는 읽을 수 있어야 한다.
- 아이콘만 있는 Button은 코드에서 Accessible Name(`aria-label` 등)을 가진다.
- 키보드로 쓸 수 있는 UI라면 눈에 보이는 Focus Indicator가 있어야 한다.
- 중요한 정보가 Hover에서만 보이지 않도록 한다.
- Link / Button / Status를 색상 차이만으로 구분하지 않는다.

## 판정 규칙
- 정확한 색상 값이 없으면 대비율을 임의로 계산하지 않는다.
- 눈으로 보기에 의심되면 `대비 부족 가능성 — 실제 색상값으로 검증 필요`로 쓴다.
- 코드의 색상 값이나 `audit.mjs` 측정값이 있으면 실제 대비율을 적는다. (예: 2.32:1 → 4.5:1 필요)
