# 콘텐츠·UX 라이팅 (Content & Copy)

팀의 UX 라이팅 원칙이 있으면 이 파일에 적어 두세요. 검수와 기획 단계 제안 모두 이 범위 안에서 이루어집니다.

## 기본 기준
- 버튼 Label은 누른 결과를 말한다. ("확인" 대신 "주문하기", "연기" 대신 "내일로 연기")
- 비슷해 보이는 버튼이 각각 무엇을 하는지 Label만 보고 구분할 수 있다.
  - 예: "우선순위"가 현재 값을 보여주는 것인지, 바꾸는 버튼인지 모호하면 "우선순위 변경"으로 쓴다.
- 오류 메시지는 원인과 해결 방법을 말한다. ("잘못된 입력" ✗ → "이메일에 @가 빠졌어요" ✓)
- 같은 개념에는 화면 전체에서 같은 용어를 쓴다. ("저장"과 "확인", "프로젝트"와 "작업공간" 혼용 금지)
- 빈 상태 문구는 왜 비었는지와 다음에 할 일을 알려준다.

## 팀 기준 (여기에 추가)
- 예: 존댓말은 "~해요" 체로 통일
- 예: 숫자와 단위 사이 띄어쓰기 규칙
