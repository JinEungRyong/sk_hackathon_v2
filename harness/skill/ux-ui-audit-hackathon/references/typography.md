# C. 타이포그래피·가독성 (Typography & Readability)

이 스킬의 기본 품질 기준(팀 기준에 맞게 수정해서 사용):

- 일반 한글 본문은 14~16px 이상을 우선한다.
- Button과 주요 Label은 14px 이상을 우선한다.
- 보조 텍스트도 12px 미만은 쓰지 않는 것을 기본으로 한다.
  - 12px는 WCAG의 필수 규정이 아니라 이 스킬이 정한 실무 최소 품질 기준이다.
- 본문 Line Height는 대략 140~160%를 우선한다.
- 한 화면의 Font Size·Weight 종류를 필요 이상으로 늘리지 않는다.
- 작은 글자와 낮은 대비를 동시에 쓰지 않는다.
- 중요한 정보에 과도한 Letter Spacing을 주지 않는다.
- 긴 한글 문장이 좁은 칸(표 셀, 카드)에서 어색하게 끊기지 않는지 본다. (`word-break: keep-all` 검토)
- 말줄임(…) 때문에 핵심 정보가 사라지지 않는지 본다.
- Metadata가 너무 작거나 흐려서 주요 정보 이해를 방해하지 않는지 본다.
- 같은 역할의 Label / Caption이 화면마다 다른 크기로 쓰이지 않는지 본다.

판정 규칙:
- 스크린샷만 보고 "12px 미만이다"라고 단정하지 않는다. 대신 `시각적으로 작아 보임 — 실제 Font Size 확인 필요(검증 필요)`로 쓴다.
- 코드나 `audit.mjs` 측정값으로 실제 크기를 확인했다면 수치로 쓴다. (예: 탭 Label 10.5px → 12px 이상)
- 크기를 올릴 때는 새 임의 값보다 기존 Type 토큰 단계를 한 단계씩 올리는 방식을 우선한다. (예: `--text-xs` → `--text-sm`)
