# 상호작용·상태 피드백 (Interaction)

- 인터랙티브 요소마다 상태가 있는가: 기본 / Hover / Pressed / Focus-visible / Disabled / Loading
- 누른 뒤 아무 반응이 없는 구간이 없는가? (로딩 표시, 버튼 비활성화로 중복 제출 방지)
- 성공·실패 결과를 사용자에게 알려주는가?
- 되돌리기 어려운 동작(삭제, 결제, 전송) 전에 결과를 예측할 수 있는가? 확인 단계나 되돌리기(Undo)가 있는가?
- 빈 상태(Empty State), 오류 상태, 데이터가 아주 많은 상태가 설계되어 있는가?
- 할 일을 다 끝낸 뒤의 화면(예: 오늘 할 일 완료 후 빈 목록)에 다음 행동 안내가 있는가?
- 버튼은 `<button>`, 이동은 `<a href>`를 쓰는가? `div onclick`은 키보드로 쓸 수 없다.
- 탭 순서가 시각적 순서와 맞는가? 양수 `tabindex`를 쓰지 않는가?
- 큰 움직임의 애니메이션은 `prefers-reduced-motion`을 존중하는가?

판정 규칙: Hover/Press/Loading, 뒤로가기 동작은 스크린샷만으로 확정하지 않는다. 코드나 실제 실행으로 확인하지 못했으면 `검증 필요`.
