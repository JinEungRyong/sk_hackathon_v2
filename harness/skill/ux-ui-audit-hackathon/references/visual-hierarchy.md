# A. 시각적 위계 (Visual Hierarchy)

- 처음 들어온 사용자가 무엇부터 봐야 하는지 분명한가?
- 화면의 Primary Action이 하나의 핵심 행동으로 읽히는가?
- Primary와 Secondary Action이 서로 지나치게 경쟁하지 않는가?
- Heading / Body / Metadata 단계가 크기·굵기·색으로 구분되는가?
- 장식 요소가 중요한 정보보다 더 강하게 보이지 않는가?
- 완료된 항목을 흐리게 처리하면서 필요한 정보까지 읽기 어려워지지 않았는가?
- Badge, Chip, 강조 Color가 한 화면에 너무 많아 시선이 흩어지지 않는가?
- 같은 강조 색이 한 화면에서 서로 다른 여러 의미(경고, 선택, 브랜드 등)를 동시에 맡고 있지 않은가?

작성 규칙: "강조가 부족하다"처럼 쓰지 말고, **사용자가 먼저 봐야 할 것**과 **현재 무엇이 그것과 경쟁하는지**를 구체적으로 쓴다.
