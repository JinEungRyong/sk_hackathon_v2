# 마케팅 랜딩 페이지 (`landing`)

- 샘플 코드: `scripts/page_types/landing.py`
- 샘플 HTML: `assets/samples/landing.html`

## 정의
제품이나 서비스 하나를 소개하고, 방문자가 **한 가지 행동**(무료 체험, 가입, 구매, 문의)을 하도록 설득하는 한 페이지짜리 사이트입니다. 위에서 아래로 스크롤하는 동안 "무엇인지 → 왜 좋은지 → 믿을 만한지 → 얼마인지 → 지금 시작하라" 순서로 설득합니다.

## 이런 경우에 씁니다
- SaaS·앱·서비스 소개, 신제품 출시, 사전 신청 페이지
- 광고를 클릭한 사람이 처음 도착하는 페이지

다른 유형과 구분: 상품이 여러 개이고 고르는 것이 중요하면 `shop`, 행사 기간이 핵심이면 `event`입니다.

## 필수 섹션 (순서대로)
| 순서 | 섹션 | 들어갈 내용 | 샘플 클래스 |
|---|---|---|---|
| 1 | 상단 메뉴 | 로고, 섹션 바로가기 3~4개, 주 CTA 버튼 | `nav` |
| 2 | 히어로 | 배지(선택), 헤드라인 1~2줄, 설명 1문장, CTA 버튼 2개(주·보조), 제품 화면 목업 | `.hero`, `.mock` |
| 3 | 신뢰 요소 | "N개 팀이 사용 중" + 고객사 로고 | `.logos` |
| 4 | 핵심 기능 | 아이콘 + 제목 + 설명 카드 3~4개 | `.feature` |
| 5 | 사용 방법 | 번호가 붙은 3단계 | `.step` |
| 6 | 고객 후기 | 별점, 인용문, 이름·직함 3개 | `.quote` |
| 7 | 요금제 | 2~3개 플랜, 추천 플랜 강조 | `.price`, `.price.pop` |
| 8 | 자주 묻는 질문 | `<details>`로 펼치는 질문 3~5개 | `details` |
| 9 | 마지막 CTA | 헤드라인 반복 + 버튼 | `.cta` |
| 10 | 푸터 | 저작권, 약관 링크 | `footer` |

요금제와 FAQ는 생략할 수 있지만, 히어로·기능·CTA는 반드시 넣습니다.

## 디자인 규칙
- 강조색은 **한 가지**만 정해 CTA 버튼, 링크, 번호 원, 체크 표시에 일관되게 씁니다. (샘플: `#4f46e5`)
- 주 CTA 버튼 문구는 페이지 안에서 똑같이 유지합니다. (예: "무료로 시작하기")
- 섹션 배경은 흰색과 아주 옅은 회색(`#f9fafb`)을 번갈아 써서 구분합니다.
- 헤드라인은 `clamp()`로 화면 크기에 따라 크기를 조절합니다.
- 상단 메뉴는 `position:sticky`로 고정합니다.

## 파이썬이 만드는 데이터
- `features`, `steps`, `reviews`, `faqs` 목록 → 카드 HTML 반복 생성
- `plans` 목록 → 가격 표시(`0원` / `19,000원 / 월` / `문의`)와 추천 플랜 강조를 조건문으로 결정

## 변형 아이디어
- 앱 홍보: 히어로 목업을 휴대폰 비율(`aspect-ratio:9/19`)로 바꿉니다.
- 사전 신청: 요금제 대신 이메일 입력 폼을 넣습니다.
- B2B: 후기 대신 도입 사례(회사명, 성과 수치) 카드를 넣습니다.

## 체크리스트
- [ ] 첫 화면(히어로)만 보고도 무엇을 하는 서비스인지 알 수 있다.
- [ ] CTA 버튼이 히어로와 페이지 하단에 모두 있다.
- [ ] 추천 플랜이 시각적으로 구분된다.
