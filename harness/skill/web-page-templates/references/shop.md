# 쇼핑몰 홈 (`shop`)

- 샘플 코드: `scripts/page_types/shop.py`
- 샘플 HTML: `assets/samples/shop.html`

## 정의
많은 상품 가운데 방문자가 원하는 상품을 **빨리 찾고 고르도록** 돕는 쇼핑몰의 첫 화면입니다. 검색, 카테고리, 기획전, 상품 목록이 중심이고, 화면 밀도가 높습니다.

## 이런 경우에 씁니다
- 패션·리빙·뷰티 등 온라인 스토어, 브랜드몰, 편집숍
- 상품 수가 많고 카테고리 탐색이 필요한 경우

다른 유형과 구분: 상품이 1~2개뿐이면 `landing`, 한정 기간 세일 자체가 주제면 `event`입니다.

## 필수 섹션 (순서대로)
| 순서 | 섹션 | 들어갈 내용 | 샘플 클래스 |
|---|---|---|---|
| 1 | 띠 공지 | 신규 가입 혜택, 무료배송 조건 한 줄 | `.notice` |
| 2 | 헤더 | 로고, 검색창, 로그인·마이페이지·장바구니 | `header`, `.search`, `.util` |
| 3 | 카테고리 메뉴 | 랭킹·신상품·카테고리·세일 메뉴, 스크롤 시 고정 | `.cats` |
| 4 | 메인 배너 | 큰 기획전 배너 1개 + 작은 특가 배너 1개 | `.banner`, `.bn` |
| 5 | 카테고리 바로가기 | 원형 아이콘 8개 | `.circles` |
| 6 | 상품 섹션 ① | 제목·부제·전체 보기 + 상품 카드 그리드 (예: 랭킹) | `.sec-head`, `.products` |
| 7 | 상품 섹션 ② | 다른 기준의 상품 목록 (예: 세일) | 위와 같음 |
| 8 | 쇼핑 혜택 | 배송, 반품, 정품, 적립 안내 4개 | `.benefits` |
| 9 | 푸터 | 사업자 정보, 고객센터, 약관 (전자상거래 사이트 필수 정보) | `footer` |

## 상품 카드 구성
이미지(3:4) → 브랜드 → 상품명(한 줄 말줄임) → **할인율(빨강) + 판매가(굵게) + 정가(취소선)** → 별점·리뷰 수. 이미지 위에 순위, 태그(단독·신상·베스트), 찜(♡)을 겹쳐 놓습니다.

## 디자인 규칙
- 기본은 흑백, 강조는 **할인 빨강**(`#e11d48`) 하나만 씁니다. 상품 이미지가 색을 담당합니다.
- 상품 그리드는 `repeat(auto-fill,minmax(200px,1fr))`로 화면 너비에 따라 열 수가 바뀌게 합니다.
- 카테고리 메뉴는 `position:sticky`, 모바일에서는 가로 스크롤(`overflow-x:auto`)로 처리합니다.

## 파이썬이 만드는 데이터
- `products` 목록(브랜드, 상품명, 정가, 할인율, 리뷰 수, 태그, 색상)
- 판매가 = 정가 × (100 − 할인율) / 100, **100원 단위 반올림**
- 랭킹 = 리뷰 수 내림차순 상위 5개, 세일 = 할인율 20% 이상을 할인율 순으로 상위 5개
- 할인율이 0이면 할인율과 정가를 표시하지 않음

## 변형 아이디어
- 식품몰: 이미지 비율을 1:1로, 태그에 "새벽배송"을 추가합니다.
- 단일 브랜드몰: 원형 카테고리 대신 컬렉션 배너 3개를 넣습니다.

## 체크리스트
- [ ] 판매가·할인율·정가가 서로 맞게 계산된다.
- [ ] 상품명이 길어도 카드 높이가 흔들리지 않는다.
- [ ] 푸터에 사업자 정보 자리가 있다.
