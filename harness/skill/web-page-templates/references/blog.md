# 블로그·매거진 홈 (`blog`)

- 샘플 코드: `scripts/page_types/blog.py`
- 샘플 HTML: `assets/samples/blog.html`

## 정의
글을 **읽게 하고, 다시 찾아오게(구독하게)** 만드는 콘텐츠 사이트의 첫 화면입니다. 글 제목과 요약이 잘 읽히는 것이 가장 중요하고, 꾸밈은 신문·잡지처럼 절제합니다.

## 이런 경우에 씁니다
- 개인·기업 블로그, 웹 매거진, 뉴스레터 아카이브, 기술 블로그

다른 유형과 구분: 작업물 이미지가 중심이면 `portfolio`, 회사 공지가 일부일 뿐이면 `corporate`의 뉴스룸으로 충분합니다.

## 필수 섹션 (순서대로)
| 순서 | 섹션 | 들어갈 내용 | 샘플 클래스 |
|---|---|---|---|
| 1 | 상단 줄 | 오늘 날짜, 로그인·구독 링크 | `.top` |
| 2 | 제호(마스트헤드) | 큰 세리프 제목 + 한 줄 소개, 가운데 정렬 | `.mast` |
| 3 | 카테고리 메뉴 | 위 굵은 선, 아래 가는 선 사이의 메뉴 | `.catnav` |
| 4 | 커버 스토리 | 큰 이미지 + 분류 + 제목 + 요약 + 글쓴이·날짜·읽는 시간 | `.featured` |
| 5 | 최신 글 목록 | 2열 카드: 이미지, 분류, 제목, 요약 2줄, 날짜·읽는 시간 | `.posts`, `.post` |
| 6 | 사이드바 | 많이 읽은 글(번호), 태그, 뉴스레터 구독 상자 | `aside` |
| 7 | 푸터 | 저작권 한 줄 | `footer` |

본문 영역과 사이드바는 `grid-template-columns:1fr 300px`로 나누고, 900px 이하에서는 한 열로 합칩니다.

## 디자인 규칙
- 종이 느낌의 배경(`#fbf8f3`), 짙은 회색 글자, 강조색은 갈색·주황 계열 하나만 씁니다.
- 제호, 글 제목, 인기 글 번호는 세리프체, 본문 요약과 메뉴는 고딕체로 구분합니다.
- 요약은 `-webkit-line-clamp:2`로 두 줄에서 자릅니다.
- 구분선(`border`)으로 영역을 나누고, 그림자는 쓰지 않습니다.

## 파이썬이 만드는 데이터
- 상단 날짜, 커버 스토리 날짜 = 오늘 (`datetime.date.today()`)
- 최신 글 날짜 = 오늘에서 3일 간격으로 거슬러 계산
- `posts`, `popular`, `tags` 목록 → 카드·순위·태그 반복 생성

## 변형 아이디어
- 기술 블로그: 이미지를 없애고 제목·요약·태그만 있는 목록형으로 바꿉니다.
- 뉴스레터: 커버 스토리 바로 아래에 구독 상자를 크게 배치합니다.

## 체크리스트
- [ ] 글 제목이 이미지보다 먼저 눈에 들어온다.
- [ ] 글 목록이 최신순이고, 날짜가 미래가 아니다.
- [ ] 구독 상자가 첫 화면이나 사이드바 상단 근처에 있다.
